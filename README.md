# 📚 BookNook

BookNook is a library management web application where users can explore books, manage their collections, and borrow or return books.

🌐 **Live Website:** https://booknook-frontend-seven.vercel.app

## ✨ Features

- Browse and explore available books.
- View detailed information about individual books.
- Add, update, and delete your own books.
- Manage personal book collections.
- Borrow and return books.
- User authentication with Better Auth.
- Responsive design for mobile and desktop devices.

## 🛠️ Technologies

- Next.js
- TypeScript
- Tailwind CSS
- MongoDB
- Better Auth
- Shadcn UI
- Lucide React

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/tanvirahmedmahin10/booknook_frontend.git
cd booknook_frontend
```

**2. Install dependencies**

```bash
npm install
```

**3. Create a `.env.local` file**

```env
NEXT_PUBLIC_SERVER_URL=https://booknook-backend-wine.vercel.app
```

**4. Start the development server**

```bash
npm run dev
```

Server runs at `http://localhost:3000`.
