# 📚 BookNook

BookNook is a library management web application where users can explore books, manage their own books, and borrow or return books.

🌐 **Live Website:** https://booknook-frontend-seven.vercel.app

## ✨ Features

- Browse and explore available books.
- View detailed information about each book.
- Add, update, and delete your own books.
- Borrow books and manage borrowed books.
- Return borrowed books.
- User authentication with Better Auth.
- Responsive design for mobile and desktop devices.

## 🛠️ Technologies

- Next.js
- TypeScript
- Tailwind CSS
- MongoDB
- Better Auth
- Shadcn UI
